# agy 生图测试：一键智能产品精修

一个网页 + 一个本地小程序（`server.js`），用你电脑上已经登录的 agy 给产品图做精修。
测试用，没有数据库、不用安装任何依赖。

## 为什么还有一个 server.js

浏览器出于安全限制，不能直接运行电脑上的程序，所以网页没法自己调 agy。
`server.js` 就是帮网页调 agy 的小程序：只用 Node 自带功能，一条命令启动，关掉终端就停了。

## 运行（Ubuntu 22 桌面，用已经登录 agy 的那个账号）

```bash
cd ai-tutu/tools/agy-refine-test
node server.js
```

浏览器打开 <http://127.0.0.1:5260>。需要 Node 18 或更新的版本（`node -v` 查看）。

可选设置（写在 `node server.js` 前面）：

| 设置 | 作用 |
| --- | --- |
| `PORT=5300` | 换端口（默认 5260） |
| `AGY_PATH=/home/sara/.local/bin/agy` | 页面顶部提示找不到 agy 时，用 `which agy` 查到路径填这里 |
| `AGY_TIMEOUT_SEC=900` | 每张图最长等多久，默认 600 秒，超时自动结束 agy |
| `--lan`（写在后面：`node server.js --lan`） | 让别的电脑也能打开，比如 VMware 外面的物理机，见下一节。等同于 `HOST=0.0.0.0` |

## 从物理机打开（Ubuntu 在 VMware 里，NAT 模式）

NAT 模式下，物理机可以直接访问虚拟机的 IP，**不需要在 VMware 里设端口转发**。

1. 在 Ubuntu 里这样启动：
   ```bash
   node server.js --lan
   ```
   终端会打印出类似这样的地址：
   ```
   其他电脑（比如 VMware 外面的物理机）打开：
     http://192.168.xxx.128:5260    （网卡 ens33）
   ```
2. 在物理机的浏览器里打开这个地址。
3. 打不开的话，按顺序检查：
   - Ubuntu 防火墙：`sudo ufw status`，如果是 active，执行 `sudo ufw allow 5260/tcp`。
   - 物理机（Windows）的“网络连接”里，**VMware Network Adapter VMnet8** 要是启用状态。
   - 物理机能不能 ping 通上面那个 IP（`ping 192.168.xxx.128`）。
4. 虚拟机重启后 IP 可能会变，以每次启动时终端打印的为准。

只有物理机自己（和同一台物理机上的其他虚拟机）能访问到，公司局域网里的其他电脑访问不到。
如果以后要让同事的电脑也能用，需要在 VMware 的“虚拟网络编辑器 → VMnet8 → NAT 设置 → 端口转发”里加一条，
或者把虚拟机网卡改成桥接模式——到时候再说。

**注意**：能打开这个页面的人，都能让 agy 在这台虚拟机上执行操作。测完后不带 `--lan` 重新启动。

## 页面功能

### 处理模式（页面最上面三个按钮）

| 参数 | 抠白底图 1:1 | 图片精修 | 自由模式 |
| --- | --- | --- | --- |
| 尺寸比例 | 🔒 1:1 | 🔒 自动（和原图 / 框选区域一样） | 可选 |
| 背景 | 🔒 白底 | 🔒 保留原图背景 | 可选 |
| 输出尺寸 | 800×800（默认）/ 1K / 2K | AI 原尺寸（默认，最清楚）/ 2K 长边 / 和原图一样大（放大，偏软） | 800 / 1K / 2K（长边）/ AI 原尺寸 |
| 输出格式 | JPG 白底 / PNG 透明底 | 🔒 JPG | JPG / PNG / PNG 透明底（仅白底） |
| 主体大小 | 可选，默认饱满 85% | 🔒 保持原图 | 可选 |
| 拍摄角度 | 可选，默认保持原图 | 🔒 保持原图 | 可选 |

- 🔒 的项由模式决定，页面上是灰色的。每个模式各自记住自己的设置，切回来还是上次的。
- **图片精修**：提示词改成“只去杂点、杂质、灰尘、划痕和噪点，提升清晰度，不改背景、构图、角度、颜色和光影”。
- **PNG 透明底**：谷歌出图没有透明通道，由程序抠：
  - 提示词要求纯白背景、不要投影、边缘干净；
  - 程序从四周往里找和外边相连的白色变透明，**产品内部的白色高光保留**；
  - 被产品围起来的大块白色（比如环形零件中间的孔）也变透明，小块白色当高光保留；
  - 背景里的零星杂点去掉；边缘 1 像素柔和过渡（去锯齿），并去掉边缘残留的白边（处理毛刺）。
  - 注意：产品边缘如果本身是很亮的白色或银色并贴着背景，可能被抠掉一点，请重点看轮廓。

### 其他

- **产品图**：点击或拖拽上传，最多 50 张（JPG / PNG / WebP）。
- **框选商品**（可选）：点缩略图，在弹出的大图上拖一个框把商品框进去。拖框内部移动，拖四个角调大小；
  “上一张 / 下一张”逐张调整；“应用到所有图片”把同一个框套用到全部；“清除框选”恢复整张。
  框选后只把框里的部分（原图全分辨率）交给 AI。
- **精修要求**：可选，原样写进提示词。
- **模型**：`agy models` 读出来的列表，默认 Gemini Flash，负责看图、写画面描述。
- **主体大小**：保持原图 / 适中 70% / 饱满 85%。白底图会由程序自动找到商品边界，精确缩放到这个比例并居中。
- **拍摄角度**：保持原图 / 自动摆正 / 正面平视 / 45° 俯视 / 正上方俯拍。改了角度会提醒核对文字和零件。
- **看大图**：点结果里的任意图片。默认完整显示在窗口内；**鼠标滚轮**以鼠标位置为中心放大缩小；
  按住拖动；双击在“适应窗口”和“1:1”之间切换；底部有 －／＋／1:1 原始像素／适应窗口／关闭；
  键盘 + - 0 也可以；Esc 或点图片外的空白处关闭。透明的地方显示成灰白格子。

### 测试设置（高级）

| 设置 | 说明 |
| --- | --- |
| 同时处理几张 | 测速度请用 1 张 |
| 越权即结束 | 默认开。委派生图**之前**：agy 只允许查看原图、委派生图子智能体，其余立即结束（然后自动重试），这时还没生图，不浪费；委派**之后**：只有运行命令、写文件、操作浏览器等危险操作才结束，其余只记警告，等它把图生成完 |
| 提示词模板 | 可直接修改。占位符：`{{图片路径}}`、`{{调用说明}}`（含 AspectRatio 和 ImagePaths 参数）、`{{角度要求}}`、`{{背景要求}}`、`{{构图要求}}`、`{{额外要求}}` |

固定做法（不用设置）：
- 让 agy 委派内部的生图子智能体 `image-generator` 出图（实测 agy 自己直接调生图工具出不了图）。
- **每张只出一张图**；图片一写好就结束 agy，省掉它等待和写总结的时间。
- 没出图时自动再试 1 次。agy 报 503 之类的错但图已经出来了，算成功，只显示警告。

### 结果区

- 每张图显示：原图（框选过的显示框选部分）、AI 原图（标出比例 ✔/✘、商品原来占多大）、最终输出（标出“主体校准 85%”“放大”等）。
- 耗时拆成三段：**准备**（开始 → 委派生图）、**生图**（→ 图片写入）、**收尾**（→ 结束 agy）。
- 显示每一步调用了什么、参数是什么；越权会标 ⚠。
- **复制结果日志**：设置、框选区域、每次尝试的耗时、生图实际参数（AspectRatio、ImagePaths、英文 Prompt）、警告、图片尺寸，复制后直接发给 AI 分析。

## 结果文件

每张图一个目录：`tools/agy-refine-test/runs/<北京时间>-<随机码>/`

| 文件 | 内容 |
| --- | --- |
| `input.jpg` | 上传的原图（agy 实际用的是系统临时目录里的一份副本，跑完自动删除） |
| `prompt.txt` | 实际发给 agy 的提示词 |
| `agy-output.ndjson` | agy 的原始输出（每行一个 JSON） |
| `out/` | 找到的生成图片 |
| `result.json` | 这一张的汇总（和页面上的结果一样） |

agy 自己也会在 `~/.gemini/antigravity-cli/brain/<会话 ID>/` 保留一份。测完可以直接删掉 `runs/` 目录。

## 这次重点看什么

1. **抠白底图 + PNG 透明底**：金属件的轮廓有没有被抠缺、有没有白边或毛刺；环形、带孔的零件中间是否透明。
2. **图片精修**：是否只去了杂点，背景、构图、颜色没被改；“AI 原尺寸”和“和原图一样大”的清晰度对比。
3. **看大图**：滚轮缩放、拖动是否顺手。
4. 有没有再出现被误判越权、白白重来的情况。
