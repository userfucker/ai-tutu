# agy 生图测试：一键智能产品精修

一个网页 + 一个本地小程序（`server.js`），用你电脑上已经登录的 agy 给产品图做精修。
测试用，没有数据库、不用安装任何依赖。

## 为什么还有一个 server.js

浏览器出于安全限制，不能直接运行电脑上的程序，所以网页没法自己调 agy。
`server.js` 就是帮网页调 agy 的小程序：只用 Node 自带功能，一条命令启动，关掉终端就停了。

## 运行（Ubuntu 22 桌面，用已经登录 agy 的那个账号）

```bash
cd ai-tutu/tools/agy-refine-test
node server.js
```

浏览器打开 <http://127.0.0.1:5260>。需要 Node 18 或更新的版本（`node -v` 查看）。

可选设置（写在 `node server.js` 前面）：

| 设置 | 作用 |
| --- | --- |
| `PORT=5300` | 换端口（默认 5260） |
| `AGY_PATH=/home/sara/.local/bin/agy` | 页面顶部提示找不到 agy 时，用 `which agy` 查到路径填这里 |
| `AGY_TIMEOUT_SEC=900` | 每张图最长等多久，默认 600 秒，超时自动结束 agy |
| `--lan`（写在后面：`node server.js --lan`） | 让别的电脑也能打开，比如 VMware 外面的物理机，见下一节。等同于 `HOST=0.0.0.0` |

## 从物理机打开（Ubuntu 在 VMware 里，NAT 模式）

NAT 模式下，物理机可以直接访问虚拟机的 IP，**不需要在 VMware 里设端口转发**。

1. 在 Ubuntu 里这样启动：
   ```bash
   node server.js --lan
   ```
   终端会打印出类似这样的地址：
   ```
   其他电脑（比如 VMware 外面的物理机）打开：
     http://192.168.xxx.128:5260    （网卡 ens33）
   ```
2. 在物理机的浏览器里打开这个地址。
3. 打不开的话，按顺序检查：
   - Ubuntu 防火墙：`sudo ufw status`，如果是 active，执行 `sudo ufw allow 5260/tcp`。
   - 物理机（Windows）的“网络连接”里，**VMware Network Adapter VMnet8** 要是启用状态。
   - 物理机能不能 ping 通上面那个 IP（`ping 192.168.xxx.128`）。
4. 虚拟机重启后 IP 可能会变，以每次启动时终端打印的为准。

只有物理机自己（和同一台物理机上的其他虚拟机）能访问到，公司局域网里的其他电脑访问不到。
如果以后要让同事的电脑也能用，需要在 VMware 的“虚拟网络编辑器 → VMnet8 → NAT 设置 → 端口转发”里加一条，
或者把虚拟机网卡改成桥接模式——到时候再说。

**注意**：能打开这个页面的人，都能让 agy 在这台虚拟机上执行操作。测完后不带 `--lan` 重新启动。

## 页面功能

### 处理模式（页面最上面三个按钮）

| 参数 | 抠白底图 1:1 | 图片精修 | 自由模式 |
| --- | --- | --- | --- |
| 尺寸比例 | 🔒 1:1 | 🔒 自动（和原图 / 框选区域一样） | 可选 |
| 背景 | 🔒 白底 | 🔒 保留原图背景 | 可选 |
| 输出尺寸 | 800×800（默认）/ 1K / 2K | AI 原尺寸（默认，最清楚）/ 2K 长边 / 和原图一样大（放大，偏软） | 800 / 1K / 2K（长边）/ AI 原尺寸 |
| 输出格式 | JPG 白底 / PNG 透明底 | 🔒 JPG | JPG / PNG / PNG 透明底（仅白底） |
| 主体大小 | 可选，默认饱满 85% | 🔒 保持原图 | 可选 |
| 拍摄角度 | 可选，默认保持原图 | 🔒 保持原图 | 可选 |
| 精修 | 可选，默认开 | 🔒 开 | 可选，默认开 |
| 清晰度 / 对比度 / 亮度 | 可选，默认原样 | 可选，默认原样 | 可选，默认原样 |

- 🔒 的项由模式决定，页面上是灰色的。每个模式各自记住自己的设置，切回来还是上次的。
- **图片精修**：提示词改成“只去杂点、杂质、灰尘、划痕和噪点，提升清晰度，不改背景、构图、角度、颜色和光影”。
- **PNG 透明底**：谷歌出图没有透明通道，由程序抠：
  - 提示词要求纯白背景、不要投影、边缘干净；
  - 程序从四周往里找和外边相连的白色变透明，**产品内部的白色高光保留**；
  - 被产品围起来的大块白色（比如环形零件中间的孔）也变透明，小块白色当高光保留；
  - 背景里的零星杂点去掉；边缘 1 像素柔和过渡（去锯齿），并去掉边缘残留的白边（处理毛刺）。
  - 注意：产品边缘如果本身是很亮的白色或银色并贴着背景，可能被抠掉一点，请重点看轮廓。

- **精修**：开 = 去瑕疵、调光线（默认）；关 = 只换背景 / 构图，产品表面、光线、颜色保持原样。
- **清晰度**：原样（默认）/ 提升清晰度。交给 AI 处理（去模糊、细节更清楚，像素数不会增加）。
- **对比度**：原样（默认）/ 稍微提高 / 明显提高；**亮度**：原样（默认）/ 稍亮 / 更亮。
  这两项由**程序**在 AI 出图后精确调整，不经过 AI，不会改动产品形状；纯白背景保持纯白。
- **颜色以原图为准**：提示词里有硬规则——产品的形状、比例、颜色必须和参考图一致；
  用户描述里写的颜色名称只作参考，和图片冲突时以图片为准（上次“黄色 / 橙色”的教训）。

### 其他

- **添加图片**：拖到浏览器页面的任意位置都可以（会出现“松开鼠标，添加图片”的提示）；也可以点产品图区域选择文件；
  或者在浏览器里“复制图片”、用截图工具截图后，回到页面按 **Ctrl+V** 直接粘贴（文件名是“粘贴图片-时分秒-序号”）。
  在输入框里粘贴文字不受影响。
- **清空**：产品图标题右边的“清空”按钮，一键清空左侧全部图片（框选、标注、取色一起清掉，右侧结果不受影响），会先确认。
- **精修要求怎么写**：简单描述产品是什么、什么材质、怎么摆放的；哪些是产品和配件、哪些是背景杂物。
  **颜色不用写**，写错颜色会把 AI 带偏；需要锁定颜色请用下面的“吸管取色”。
- **产品图**：点击或拖拽上传，最多 50 张（JPG / PNG / WebP）。
- **框选商品 / 标注配件**（可选）：点缩略图打开大图，上方有三个工具：
  - **框选商品**：拖一个框把商品框进去。拖框内部移动，拖四个角调大小；“应用到所有图片”把同一个框套用到全部；“清除框选”恢复整张。
    框选后只把框里的部分（原图全分辨率）交给 AI。
  - **画笔标注配件**：在容易被当成杂物的小配件上涂抹（显示成红色），连在一起的涂抹算一个配件。粗细可调。
  - **橡皮擦**：擦掉涂错的地方；“清除标注”一键清空这张图的标注。
  - **吸管取色**：在产品上点一下，取原图那一点的颜色（色号，例如 #F0882A），可以写备注（例如“无线充”），最多 8 个。
    提示词会写明“这些部位必须保持这个颜色”，用色号代替颜色词。缩略图上标“颜色×2”。
  - 下方可以填**配件说明**（选填），比如“右边两个白色塑料插头是配件，必须保留”。
  - 有标注时，交给 AI 的是：原图 + **配件标注图**（红框 + 编号）+ **配件特写**（每个配件放大一张，最多 4 张）。
    提示词会要求 AI 完整保留这些配件、不要画出红框。结果卡片会显示标注图，并提醒“请核对配件是否都在”。
  - 标注不做“应用到所有图片”（每张图配件位置不同）。框选范围外的标注不生效。
  - 缩略图上会标“已框选 · 配件×2”。
  - 没有标注时，提示词也会默认要求“所有零件、配件、线缆都是产品的一部分，要完整保留”。
- **精修要求**：可选，原样写进提示词。
- **模型**：`agy models` 读出来的列表，默认 Gemini Flash，负责看图、写画面描述。
- **主体大小**：保持原图 / 适中 70% / 饱满 85%。白底图会由程序自动找到商品边界，精确缩放到这个比例并居中。
- **拍摄角度**：保持原图 / 自动摆正 / 正面平视 / 45° 俯视 / 正上方俯拍。改了角度会提醒核对文字和零件。
- **看大图**：点结果里的任意图片。默认完整显示在窗口内；**鼠标滚轮**以鼠标位置为中心放大缩小；
  按住拖动；双击在“适应窗口”和“1:1”之间切换；底部有 －／＋／1:1 原始像素／适应窗口／关闭；
  键盘 + - 0 也可以；Esc 或点图片外的空白处关闭。透明的地方显示成灰白格子。

### 额度（页面顶部）

- 页面顶部显示 **Gemini 额度**：5 小时窗口、每周窗口各剩多少、什么时候重置，点“刷新”重新查。
  用的是 `agy -p /usage`，**查询本身不调模型、不耗额度**（和 Claude Code WebUI 一样的办法）。
- 开着“每张做完查一次额度”时（默认开），每张图做完自动查一次，卡片上显示
  “额度 5 小时 -3.2% · 本周 -0.8%”；结果区顶部汇总“每张平均用掉多少，照这样 5 小时约几张、一周约几张”。
  同时处理多张时没法分到每张，只看顶部额度变化。每张会多等几秒（agy 启动查询的时间）。
- **额度不足自动暂停**：agy 报“额度用完 / 请求太频繁”（RESOURCE_EXHAUSTED、429、quota 等）时，这张**不重试**，
  放回队首，整个队列暂停：额度快见底时等到重置时间，否则先等 30 分钟，然后自动继续。
  暂停期间结果区顶部有黄色提示条和倒计时，可以点“立即继续”。
- **低于设定值自动暂停**（高级设置，默认不暂停）：剩余低于 10% / 20% 时暂停到重置时间。
- **每张之间间隔**（高级设置，默认不间隔）：30 秒 / 1 分钟 / 3 分钟，避免连续提交触发频率限制。
- **快速模式**（高级设置，默认关）：负责写描述的 AI **不看原图**，直接把程序拼好的英文要求原样交给生图子智能体
  （子智能体自己通过参考图看产品）。更省额度、更快，但描述没那么具体。开了快速模式时不用提示词模板。

### 测试设置（高级）

| 设置 | 说明 |
| --- | --- |
| 模板语言 | 英文（默认，推荐）/ 中文。生图模型最终收到的就是英文，规则直接用英文写更准确。中英文模板各自保存，可以切换对比 |
| 每张之间间隔 | 不间隔 / 30 秒 / 1 分钟 / 3 分钟 |
| 额度低于多少自动暂停 | 不暂停 / 10% / 20% |
| 同时处理几张 | 测速度、测每张额度请用 1 张 |
| 越权即结束 | 默认开。委派生图**之前**：agy 只允许查看原图（和标注图）、委派生图子智能体，其余立即结束（然后自动重试），这时还没生图，不浪费；委派**之后**：只有运行命令、写文件、操作浏览器、调用外部工具这类会动电脑的操作才结束，其余（比如用 schedule 等待）只记警告，等它把图生成完 |
| 提示词模板 | 可直接修改。占位符：`{{图片路径}}`、`{{要看的图}}`、`{{调用说明}}`、`{{颜色锁定}}`、`{{配件要求}}`、`{{角度要求}}`、`{{精修要求}}`、`{{清晰度要求}}`、`{{背景要求}}`、`{{构图要求}}`、`{{额外要求}}` |

固定做法（不用设置）：
- 让 agy 委派内部的生图子智能体 `image-generator` 出图（实测 agy 自己直接调生图工具出不了图）。
- **每张只出一张图**；图片一写好就结束 agy，省掉它等待和写总结的时间。
- 没出图时自动再试 1 次。agy 报 503 之类的错但图已经出来了，算成功，只显示警告。

### 结果区

- 每张图显示：原图（框选过的显示框选部分）、AI 原图（标出比例 ✔/✘、商品原来占多大）、最终输出（标出“主体校准 85%”“放大”等）。
- 耗时拆成三段：**准备**（开始 → 委派生图）、**生图**（→ 图片写入）、**收尾**（→ 结束 agy）。
- 显示每一步调用了什么、参数是什么；越权会标 ⚠。
- **复制结果日志**：设置、框选区域、每次尝试的耗时、生图实际参数（AspectRatio、ImagePaths、英文 Prompt）、警告、图片尺寸，复制后直接发给 AI 分析。

## 结果文件

每张图一个目录：`tools/agy-refine-test/runs/<北京时间>-<随机码>/`

| 文件 | 内容 |
| --- | --- |
| `input.jpg` | 上传的原图（agy 实际用的是系统临时目录里的一份副本，跑完自动删除） |
| `prompt.txt` | 实际发给 agy 的提示词 |
| `agy-output.ndjson` | agy 的原始输出（每行一个 JSON） |
| `out/` | 找到的生成图片 |
| `result.json` | 这一张的汇总（和页面上的结果一样） |

agy 自己也会在 `~/.gemini/antigravity-cli/brain/<会话 ID>/` 保留一份。测完可以直接删掉 `runs/` 目录。

## 这次重点看什么（测额度）

同时处理选 **1 张**，“每张做完查一次额度”保持打开，然后各跑 5～10 张：

1. **普通模式 + Flash High**（现在的默认）
2. **普通模式 + Flash Low / Medium**（在“模型”下拉框里换）
3. **快速模式 + Flash High**

每组做完点“复制结果日志”发给我。日志里有每张的额度消耗和“5 小时约几张、一周约几张”的估算，
三组对比就知道哪种最省、效果差多少。另外，如果遇到“额度不足自动暂停”，把那段日志也发我。
