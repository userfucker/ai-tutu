# AI图图 · 电商作图助手（浏览器插件，Gemini / Copilot）v0.4.0

在 **Gemini 网页版**（gemini.google.com）和 **Copilot 网页版**（copilot.com）右侧加一个面板，批量做 **抠白底图 / 产品精修**：
插件负责新建对话、贴图、填英文提示词、发送、收回 1024 原图，再做主体校准、透明底、调色、缩放，最后单张下载或打包 zip。
图片处理代码和 agy 测试页面是同一份（`lib/imagekit.js`）。

## 安装（Edge / Chrome）

1. 先把 **探测插件（Gemini 页面探测 / Copilot 页面探测）关掉或删除**，和本插件同时开会互相干扰。
   **Copilot 只能用谷歌浏览器**：Edge 不允许任何插件在 Copilot 网页上运行。
2. 解压 zip，得到 `extension` 文件夹。
3. Edge 打开 `edge://extensions`（Chrome 打开 `chrome://extensions`），打开左下 / 右上的 **开发者模式**。
4. 点 **加载解压缩的扩展**，选 `extension` 文件夹（里面直接能看到 `manifest.json`）。
5. 打开或刷新 https://gemini.google.com/app （或 https://copilot.com ），右侧出现黑色把手 “AI 图图 ▶”。点把手可以左右收起 / 展开。

升级：用新文件夹覆盖旧文件夹，在扩展页点插件上的 **重新加载**，再刷新 Gemini 页面。
0.1.1 新增了“读取 googleusercontent 图片”的权限（为了取 3.1 Pro 出的图），重新加载时浏览器可能提示新权限，同意即可。

## 使用

1. **选模式**：抠白底图 1:1 / 图片精修（跟原图比例）/ 自由模式。
2. **加图片**：点虚线框选择，或者把图片**拖到面板任意位置**，或者先点一下面板再按 Ctrl+V。
   点缩略图可以 **框选商品、画笔标注配件、吸管取色**（和测试页面一样）。
3. 写 **精修要求**、选输出尺寸 / 格式等。
4. **批量设置**：
   - 每批张数：自己填（默认 10）。一批只做还没打 ✓ 的图。
   - 发送方式：
     - **B：插件自动发送**。每张之间随机等 20～60 秒。遇到被拒、人机验证、额度提示、出错会 **自动停下**；Gemini 标签页切到后台会 **暂停**，切回来继续。
     - **A：插件填好，我按回车**。插件填好图和提示词后提示你，你检查一下按回车，插件接着收图、做下一张。
   - 会话方式：**每张新会话**（默认）/ **当前会话连续做**（提示词会说明这是一个新的独立产品）/ **每 N 张换新会话**（N 自己填）。
5. 点 **开始这一批**。随时可以点 **停止**。做的时候请让 Gemini 标签页留在前台，不要在 Gemini 输入框里打字。
6. 结果区：每张可 **下载**、**看 AI 原图**；被拒 / 失败 / 停止的可以 **重做这张**；**打包下载 zip** 下载本次所有完成的图。
   文件名：`原名-白底-800x800.jpg`、`原名-精修-…`、`原名-处理-…`。
7. 有问题点 **复制日志** 发给我（含每张的步骤、耗时、Gemini 回复和第一张的提示词）。

## 白底和透明底（0.2.0）

- **白底提纯**：白底图（抠白底 / 选了白底）时，AI 出的背景如果是乳白、偏黄、偏灰，程序按背景颜色把整张图校正，背景变纯白，产品一起校正（不会出现一块白一块乳白的分界）。结果上会写“白底提纯（原背景 RGB …）”。
- **PNG 透明底**：只抠和图片四周相连的纯白，碰到轮廓就停，产品内部的白色高光保留。
  - “镂空处”默认 **保留**（金属件选这个）；戒指、环形零件这类中间有洞的产品选 **也抠透明**。
  - 产品边缘如果是和背景连成一片的纯白（中间没有轮廓线），还是可能被抠掉一点，请看轮廓。
- **去污渍**：精修打开时，提示词里明确要求去掉污渍、油渍、指纹、水印、锈点、变色，并且不要新加污渍。

## Copilot（0.2.1）

- Copilot 有**两套页面**，插件都认：
  - 工作版样子（copilot.com/chat/conversation/…，按钮是 Fluent 风格）
  - 个人版样子（www.copilot.com/chats/…，输入框是“向 Copilot 发送消息”的大输入框）
- Copilot 有时不出图、只回一段参数文字（实测回了 `{"orientation":"square"}`）：插件会在同一个对话里**催一次**“请直接生成这张图片”，还不出图才算没出图。

- 页面结构来自 Copilot 探测报告（谷歌浏览器，copilot.com）。贴图会依次试“粘贴 / 文件框 / 拖放”，哪种有效记住哪种。
- Copilot 不切换模型（面板上不显示模型选项），日志里记录当前模式（如“Copilot 自动”）。
- Copilot 生图时会先回一句话再画图（约 40 秒），插件会等到图出来；回复结束 8 秒还没有图才算没出图。
- 实测 Copilot 出的图是 1536×1024，白底图会自动按主体校准成 1:1。

## 0.4.0 改动

- 标题只写“AI图图 · 电商作图 · Gemini / Copilot”，去掉了说明文字；去掉了“复制日志”。
- 产品图缩略图一律是小正方形（一行 6 张），图片完整放在里面；点开后再框选。
- 结果更简洁：文件名超过 10 个字只显示前 10 个（鼠标停上去看全名）；“完成 xx 秒”只显示一次；
  PNG 不再写“透明底”；“白底提纯 · Copilot Smart”合成一个标签。
- **重做就在原记录上重做**，不新加记录（失败的记录做好后变成完成）。
- **设置**里新增：每张最多重试几次（默认 3）；□ 重试时打开新会话（默认不勾，在原对话里重发）；
  ☑ 没出图时先发一句“怎么回事不生成图片？”（默认勾选）。
- **精修要求不保存**：刷新页面或重开浏览器后清空，免得上一个产品的描述带到下一个产品。
- **刷新页面图片还在**：已上传的产品图和做好的结果，刷新页面、网页自己重载都保留；关掉这个标签页或关掉浏览器才清空。
- **镂空处**新增“自动（推荐，默认）”：被产品围住的白色，周围是叶子、泥土这类有颜色的算空隙抠掉（树苗枝叶间那块白），
  周围是灰色金属的算高光保留。另外两个选项：保留（白色都不抠）/ 都抠透明。
  提示词里也要求“枝叶之间、把手里、零件之间的空隙露出同样的纯白背景”。
- Copilot 会话管理可以折叠（点标题），默认收起。

## 0.3.0 新增

- **结果多选**：每条结果前有勾选框，可以“全选”，然后 **重做选中 / 下载选中 zip / 删除选中**。
- **删除**：每条结果有“删除”按钮，结果和面板里对应的产品图一起删掉（正在做的那张不能删）。去掉了“看 AI 原图”按钮（点结果里的图就能看）。
- **设置**（“复制日志”左边）：
  - 每张间隔：两个数字自己填（比如 10～30），每张之间在这个范围里随机等（只用于 B 自动发送）。
  - 失败后等待几秒再重试。
  - 被拒或出错时：**自动停止**，或 **自动重试**（同一张等几秒再做 1 次；还不行就记下来，接着做下一张，不停）。
  - 出现人机验证、额度 / 频率限制时总是停下。
  - 这些设置和其他设置一样按网站分开保存。
- **Copilot 会话管理**（面板最下面，只在 Copilot 页面出现）：点“读取左侧会话” → 勾选 → “删除选中”（会再确认一次，删除后找不回来）。
  只能读到左侧已经显示出来的会话，要删更早的先在左侧往下滚动再读取。两套 Copilot 页面都支持。

## 注意

- **Gemini 模型**（批量设置里）：Flash（默认，推荐）/ Pro / Flash-Lite / 不切换。每张发之前插件会看一眼网页上的模型，不对就自动切（新对话里模型按钮出来得晚，最多等 10 秒）；切不成也不停下，按网页当前模型继续，结果上的模型标签变黄带 ⚠；**扩展思考** 可选 不管 / 开 / 关。日志和结果里会写这张用的是哪个模型。
- 面板里的图都做过（打了 ✓）时点“开始这一批”，会问你要不要全部再做一遍（比如换了模型）。

- Gemini 网页改版后，插件可能找不到输入框 / 按钮，会提示“等待超时：……”。把日志发我，改 `content/gemini.js` 里的 `GEM` 选择器即可。
- 插件只在 gemini.google.com 页面运行，不上传任何数据到别处；设置保存在浏览器本地。

## 文件

| 文件 | 内容 |
| --- | --- |
| `manifest.json` | 插件声明（MV3） |
| `background.js` | 后台：替页面取网络地址的生成图（3.1 Pro 的图在 googleusercontent 上） |
| `lib/imagekit.js` | 和测试页面共用的图片处理（白底提纯、透明底、调色）+ 提示词 + zip |
| `content/common.js` | 各网站共用：等待、后台取图 |
| `content/gemini.js` | Gemini 页面自动操作（选择器集中在 `GEM`） |
| `content/copilot.js` | Copilot 页面自动操作（选择器集中在 `COP`） |
| `content/panel.js` | 右侧面板、编辑器、批量流程、结果和下载（两个网站共用，网页操作走 `AITUTU_SITE`） |
