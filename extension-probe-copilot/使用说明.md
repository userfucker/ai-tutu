# AI图图 · Copilot 页面探测插件（Chrome / Edge 通用）

做 Copilot 版作图插件之前，先摸清 Copilot 网页的结构：输入框在哪、怎么上传图片、发送 / 停止按钮是哪个、
生成的图片在哪、能不能取到原图、被拒或额度用完时页面上显示什么。
你在 Copilot 里手动做一遍，插件在旁边记录，最后生成一份报告发给 AI。

支持的网址：`copilot.microsoft.com`（个人版）、`m365.cloud.microsoft` / `copilot.cloud.microsoft`（工作账号版）、
`www.bing.com/chat`、`www.bing.com/images/create`（Bing 图像创建者）。

报告里会有：按钮和输入框的名字和位置、侧边栏按钮和对话标题、最后几条消息的前 200 个字（用来认出“被拒 / 额度”提示）、
图片地址（中间截掉一部分）。报告先显示在面板里，你看过再发。

## 安装

1. **先关掉 Gemini 的探测插件和 AI图图 Gemini 插件**（不关也行，它们只在 Gemini 页面运行，不会冲突；关掉更清爽）。
2. 解压，得到 `extension-probe-copilot` 文件夹，放在固定位置。
3. Edge 打开 `edge://extensions`（Chrome 打开 `chrome://extensions`），打开 **开发者模式**。
4. 点 **加载解压缩的扩展**，选 `extension-probe-copilot` 文件夹。
5. 打开（或**刷新**）https://copilot.microsoft.com ，**右上方**出现“AI图图 · Copilot 探测”小面板。
   挡住按钮时，按住标题栏拖到别处，或点“收起”。

### 面板没出现怎么办（0.1.1）

1. 先按 F5 刷新 Copilot 页面（装插件之前就打开的页面，插件不会自动进去）。
2. 还没有：点浏览器右上角的拼图图标（扩展），找到“AI图图 · Copilot 页面探测”，点一下它。
   - 图标上显示绿色 **OK**：面板应该出现了。
   - 显示红色 **ERR**：鼠标停在图标上，会显示放不进去的原因，把这句话发给 AI。
3. 还不行：按 F12 打开开发者工具，点“控制台（Console）”，在过滤框输入 `AI图图`，把看到的内容截图发给 AI。

## 使用（约 3 分钟）

1. 点 **① 开始录制**。
2. 在 Copilot 里**像平时一样手动做一遍**：
   上传一张产品图 → 输入一句话（比如“把这个产品做成白底电商图，1:1”）→ 发送 →
   等图片生成出来 → **点开大图** → 点**下载**。
3. 点 **② 停止录制**。
4. 点 **③ 测试取图**：测试插件能不能直接拿到刚生成的图、原图多大。
5. 点 **④ 试填测试**：插件用 3 种方法往输入框填测试文字，再用 3 种方法放 TEST 灰色图片（约 15～30 秒）。
   **不会发送**。测完请**自己把输入框里的文字和 TEST 图片删掉**。
6. 点 **⑤ 生成报告并复制**，把报告粘贴发给 AI。

如果方便，再多做两件事，各生成一份报告（每次做之前点“① 开始录制”）：
- 让 Copilot 生成一张它会拒绝的图，或者额度用完时的样子 —— 用来认出“被拒 / 额度”提示。
- 点左边的“新聊天”按钮 —— 用来找“发起新对话”。

## 测完以后

在扩展管理页里把它关掉或删除即可。
